BIT504 – Assessment 1

Introduction
This project is a Java console application developed for BIT504 Assessment 1.
The goal is to help a classroom teacher interpret student marks more easily by reading data from a text file and generating clear, formatted reports.

The application loads student information from students.txt, stores it using object‑oriented classes, and provides multiple reporting options through a console menu.


Features
- Load and parse student data from a file
- Display all students in a formatted table
- Display an individual student by ID
- Show the top student for each course
- Generate a class report with averages and grades
- Exit option with a closing message


Classes
- Main – Loads data, displays menu, handles user input
- Student – Stores student details and course marks
- Course – Stores a course name and mark
- Report – Generates student and class reports


Data File
students.txt contains:
ID, FirstName, LastName, Math, Art, History, Science, Geography, Economics, Literature
